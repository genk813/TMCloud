## 3. プログラムの部品を理解しよう 🧩

### 関数（かんすう）= 仕事をする箱

```python
# 関数は「入力」を受け取って「出力」を返す箱

         [入力]
           ↓
    ┌─────────────┐
    │   関数の箱   │
    │  （処理）    │
    └─────────────┘
           ↓
         [出力]

# 実際の例
def add_numbers(a, b):  # aとbを受け取る
    result = a + b      # 足し算する
    return result       # 結果を返す

# 使い方
answer = add_numbers(3, 5)  # 3と5を入れる
print(answer)  # 8が出力される
```

### クラス = 機能をまとめた道具箱

```python
# クラスは関連する機能をまとめたもの

class Calculator:  # 電卓クラス
    ┌─────────────────────────┐
    │     Calculator          │
    ├─────────────────────────┤
    │ + add()      足し算     │
    │ + subtract() 引き算     │
    │ + multiply() 掛け算     │
    │ + divide()   割り算     │
    └─────────────────────────┘

# 使い方
calc = Calculator()  # 電卓を作る
result = calc.add(10, 5)  # 10+5を計算
```

## 4. SQLの仕組みを図解 📊

### SQL = データベースと話す言語

```sql
SELECT * FROM trademark_search WHERE search_use_t LIKE '%プル%'
```

これを日本語にすると：

```
「trademark_searchテーブル」から
「search_use_tカラム」に「プル」を含む
「全ての行（*）」を
「選んで（SELECT）」ください
```

## 5. エラーが起きたときの流れ 🚨

### エラー処理の仕組み

```python
try:
    # 危険な処理を試す
    ┌─────────────────┐
    │  データベース    │
    │   に接続...     │
    └─────────────────┘
           ↓
    [成功？失敗？]
           ↓
except エラー:
    # エラーが起きたときの処理
    ┌─────────────────┐
    │  エラーメッセージ│
    │   を表示        │
    └─────────────────┘
```

### 実際の例

```
ユーザー: 「あいうえお」で検索
           ↓
    [検索を実行]
           ↓
    ❌ エラー発生！
    データベースが見つかりません
           ↓
    [エラー処理]
    「申し訳ありません。
     データベースに接続できません」
           ↓
    プログラムは停止せず続行
```

## 8. デバッグ（バグ取り）のコツ 🐛

### バグの見つけ方

```python
# デバッグの基本: print文を使う

def search(keyword):
    print(f"1. 検索開始: {keyword}")  # ここまで来た？
    
    results = database.search(keyword)
    print(f"2. 検索結果: {len(results)}件")  # 結果は？
    
    if results:
        print("3. 結果あり")  # この分岐に入った？
        return results
    else:
        print("3. 結果なし")  # それともこっち？
        return []
```

### エラーメッセージの読み方

```
エラー例:
TypeError: unsupported operand type(s) for +: 'int' and 'str'
    ↓
翻訳すると:
「型エラー: 数字と文字を足し算できません」

原因:
3 + "hello"  # 数字と文字は足せない

解決:
3 + 5        # 数字同士ならOK
"3" + "hello"  # 文字同士ならOK
```

### 🌟 大切なポイント

1. **エラーは友達**
   - エラーメッセージは問題を教えてくれる
   - 恐れずに読んで理解しよう

2. **小さく始める**
   - いきなり大きなプログラムは作らない
   - 小さい部品から作って組み合わせる

3. **真似から始める**
   - 良いコードを真似することから始めよう
   - 理解したら自分なりにアレンジ

4. **楽しむことが一番**
   - 動いたときの喜びを大切に
   - 失敗も学びの一部
