## 1. ファイルヘッダー部分（1-17行目）

### 1-2行目：シェバンとエンコーディング宣言

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
```

#### 詳細解説：

**1行目：`#!/usr/bin/env python3`**
- これは「**シェバン（shebang）**」と呼ばれる
- LinuxやMacで、このファイルを直接実行可能にする
- `./tmcloud_search_integrated.py`と実行したときに、Python3で動かすことを指定
- Windowsでは無視されるが、書いておくことで互換性を保つ

**2行目：`# -*- coding: utf-8 -*-`**
- ファイルの文字エンコーディングを**UTF-8**と明示
- 日本語（ひらがな、カタカナ、漢字）を正しく扱うために必要
- Python3ではデフォルトでUTF-8だが、明示的に書くのが良い習慣

### 3-17行目：docstring（ドキュメント文字列）

```python
"""
TMCloud 統合検索システム
Version: 2.0
Date: 2025-08-08

TMSONAR仕様準拠の統合検索システム
- 商標名検索（FTS5、文字統一処理）
- 称呼検索（TMSONAR準拠5段階処理）
- 番号検索（出願番号・登録番号）
- 日付範囲検索（和暦対応）
- ステータス検索
- 類似群コード検索（前方一致対応）
- 指定商品/役務検索（項目内AND）
"""
```

#### 詳細解説：

- `"""` で囲まれた複数行の文字列は**docstring**
- モジュール（ファイル）全体の説明を書く
- `help(モジュール名)`で表示される
- **TMSONAR**は特許庁の商標検索システム
- このシステムがTMSONARの仕様に準拠していることを明記
- 主要機能を箇条書きで列挙

**各機能の意味：**
- **FTS5**：SQLiteの全文検索エンジン（Full Text Search version 5）
- **文字統一処理**：全角/半角、旧字体/新字体などを統一
- **称呼**：商標の読み方（「コカコーラ」の称呼は「コカコーラ」）
- **5段階処理**：TMSONARの称呼検索アルゴリズム
- **和暦対応**：令和、平成、昭和などの日本の元号
- **前方一致**：文字列の先頭が一致するか検索
- **項目内AND**：複数条件を全て満たす検索

## 3. TextNormalizerクラス - 概要（33-35行目）

```python
class TextNormalizer:
    """テキスト正規化ユーティリティ（TMSONAR準拠）"""
```

#### 詳細解説：

**33行目：`class TextNormalizer:`**
- **クラス定義**の開始
- クラス名は**CamelCase**（単語の頭を大文字）で書く
- テキストを正規化（標準化）するための機能をまとめたクラス

**34行目：docstring**
- クラスの説明文
- **TMSONAR準拠**：特許庁の商標検索システムと同じ正規化ルール
- このクラスが何をするか一目でわかる

### なぜテキスト正規化が必要か？

商標検索では、同じ意味の文字でも様々な表記があります：

```
例1：「カフェ」の表記バリエーション
- カフェ（カタカナ）
- ｶﾌｪ（半角カタカナ）
- cafe（英語小文字）
- CAFE（英語大文字）
- Ｃａｆｅ（全角英語）
- 珈琲（漢字）

例2：数字の表記
- 3（半角）
- ３（全角）
- Ⅲ（ローマ数字）
- 三（漢数字）
```

これらを統一しないと、検索で見つからない問題が発生します。

#### 詳細解説：

**47-89行目：旧字体→新字体の膨大な対応表**

この変換テーブルは日本語の歴史的な文字変遷に対応：

1. **戦前の旧字体**（例：國、學、會）
2. **戦後の新字体**（例：国、学、会）

**なぜ必要か？**
- 古い商標には旧字体が使われている
- 企業名や人名に旧字体が残っている
- 検索時に両方を見つける必要がある

**重要な変換例：**
```python
'國':'国'    # 國際→国際
'學':'学'    # 大學→大学
'會':'会'    # 會社→会社
'實':'実'    # 實業→実業
'證':'証'    # 證券→証券
'專':'専'    # 專門→専門
'體':'体'    # 體育→体育
'臺':'台'    # 臺灣→台湾
```

**特殊なケース（86-88行目）：**
```python
'嶋':'島'    # 人名でよく使われる異体字
'濵':'浜'    # 地名の異体字
'髙':'高'    # 「はしごだか」と呼ばれる異体字
'﨑':'崎'    # 「たつさき」と呼ばれる異体字
```

これらは**人名・地名**で特によく見られる異体字で、商標検索では重要。

#### 詳細解説：

**ギリシャ文字が商標で使われる理由：**
1. **科学・数学系ブランド**（α、β、γ、Δ、Σ、π）
2. **医薬品**（多くの薬品名にギリシャ文字）


**実際の使用例：**
- `αケア` → `aケア`
- `βカロテン` → `bカロテン`
- `Δプラン` → `Dプラン`
- `ΩWATCH` → `OWATCH`
