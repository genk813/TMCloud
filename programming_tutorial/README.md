# 📚 TMCloud プログラミング学習教材

中学生向けのプログラミング学習教材です。

## 📁 ファイル構成

1. **TMCloud_Programming_Tutorial.md**
   - メイン教材（基本概念の説明）

2. **TMCloud_Visual_Guide.md**
   - ビジュアルガイド（図解中心）

3. **TMCloud_Practice_Problems.md**
   - 練習問題集（レベル別）

4. **sample_for_beginners.py**
   - 実際に動かせるサンプルプログラム

## 🎯 学習の進め方

1. まず`TMCloud_Programming_Tutorial.md`を読んで基本を理解
2. `TMCloud_Visual_Guide.md`で図解を見ながら復習
3. `sample_for_beginners.py`を実行して体験
4. `TMCloud_Practice_Problems.md`で練習問題に挑戦

## 💻 サンプルプログラムの実行方法

```bash
python3 sample_for_beginners.py
```

## 📝 対象レベル

- プログラミング初心者（中学生以上）
- Pythonの基礎を学びたい人
- データベースの仕組みを理解したい人
